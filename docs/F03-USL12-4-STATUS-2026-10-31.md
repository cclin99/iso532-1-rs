## 0. 一句話結論

現有測試**無法分辨** 0.22 與 0.24（兩值在每個可觸發案例上都落在 Annex B 容差內）；權威來源方面**已確認 ISO 532-1:2017 的 2017-11 修正版確實更正了 Table A.9**，但更正的是哪一格、由何值改為何值、原因為何，全部未知；實作沿革上 0.22 與 0.24 各有一手來源。改表門檻維持 PENDING，`tables.rs:86` 維持 0.24。

## 3. 這格影響多大

- 量到的最大影響：時間加權前總響度 0.016 sone、比響度 0.010 sone/Bark（定向人工輸入）；真實 Annex B 訊號 14 的總響度對 C 的殘差從 0.0151 變 0.0128 sone。Annex B 容差在這些量級是 0.1 sone 以上。
- 以 MoSQITo golden 做 parity 的測試若改 0.22 會斷掉；那證明與 MoSQITo 不同，不證明違反 ISO。

# F-03 `USL[12][4]` (0.24 vs 0.22): status and options after three independent rounds

Date: 2026-10-31 (Asia/Taipei). Snapshot `d623d32`. Compiled by the main agent (Claude) from three deliveries by Astra (`gpt-6-astra`) for the user's decision; the original reports are in Chinese under `docs/verification/2026-10-31-F03-*-d623d32/`. No code or table change.

## 0. One-sentence conclusion

The existing tests **cannot discriminate** 0.22 from 0.24 (both stay inside the Annex B tolerance on every case that touches the cell); on the authority side it is **confirmed that the 2017-11 corrected version of ISO 532-1:2017 did correct Table A.9**, but which cell, from what to what, and why remain unknown; on the implementation-history side both 0.22 and 0.24 have first-hand sources. The change gate stays PENDING and `tables.rs:86` stays 0.24.

## 2. Evidence scoreboard (implementation history, not the normative value)

| 0.22 | 0.24 | Unknown |

A notable tension: SQAT claims descent from the "2014 Annex A C program" yet carries 0.24, while the archived official C is 0.22f. Two explanations: the 2014 C differed from the archived attachment (implying the C attachment was updated, possibly with the 2017-11 correction), or AARAE changed the value in transcription. This is a **hypothesis**; it can be tested by obtaining the AARAE 2015 source and the 2014 C file, which needs no paid standard.

## 3. How much this cell matters

- Used only when a band-edge specific loudness falls in the 0.30–0.42 sone/Bark segment and the band index is 4; it sets the high-frequency slope of the specific-loudness pattern there.
- Largest measured effect: 0.016 sone total loudness before temporal weighting and 0.010 sone/Bark specific loudness (synthetic input); on real Annex B signal 14 the total-loudness residual against C moves from 0.0151 to 0.0128 sone. The Annex B tolerance at these magnitudes is at least 0.1 sone.
- MoSQITo-golden parity tests would break under 0.22; that proves a difference from MoSQITo, not a violation of ISO.
