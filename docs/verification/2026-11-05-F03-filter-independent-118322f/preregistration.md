3. Read workbook numeric values afresh. Compare stationary N and all 240 N′ bins, time-varying N for 6–25 and available N′ trace for 6–13 (column L at the Bark coordinate named in row 9). Match by integer 0.0001 s ticks, verify exact coverage and 0.002 s grid. No interpolation, nearest-neighbour or clipped indexing. Do not compare a flush tail to a workbook row that does not exist. Record input length, output lengths, first/last matched times and unmatched tails. Ordinary claim gate: max absolute difference <= 0.0001 + 1e-10 (CSV/workbook quantization); decisive separation >= 0.0002 - 1e-9, equality < 0.00005. Also report integer-quantized decisive counts to audit floating tie effects.
4. Four WAV factorial experiment: full-precision original PCM converted using (a) 2sqrt2 and (b) calibration-WAV RMS coefficient. Frontends: current Rust noct, Annex A reference filter + RMS after skip, with the same Rust main/slopes backend (0.24). Freeze `skip=0.2` as primary; test 0, 0.1, 0.2, 0.4 s sensitivity while retaining filter startup history. Separately identify cropped-input noct (resets state) versus full-filtered-signal RMS skip. Quantify filter-only delta under each calibration and calibration-only delta under each frontend, interaction and remaining N/N′ error. Claim gate for Annex A + 2sqrt2: each N error <=0.001%; record strict result without relaxing it. Compare candidate frontend against unchanged official C at the same calibration to <=0.0001 sone (N and N′), using full-precision DLL as an additional control.
5. USL is a separate controlled factor: compare C 0.22 vs 0.24 on identical frontend levels and PCM, and verify stationary 2–5 sensitivity. Do not attribute calibration changes to filters. Separate numerical consistency from historical provenance and corrected Table A.9 authority.
