- **F-07.** In the cell where a slope segment ends before the sampling position, the specific loudness is the value of the segment containing the sampling position (a later slope segment or the core value), no longer an extrapolation; the total is bitwise unaffected by F-07.
- **C golden (D4 revised).** Generated from the official `ISO_532-1.c` (SHA-256 `a74b45ed297cd09ac60701a923120341137d227e536f3109ae4ece810d834491`) with only `USL[12][4]` changed `0.22f` → `0.24f`; three tiers: the four C-01 tail points at 1e-10 for total and specific; whole-series total 1e-4 sone; whole-series specific 3e-4 sone/Bark. - **Unchanged.** API, output grid (`ceil(ceil(L/24)/4)`), stream contract (batch = stream bitwise), SIMD dispatch, C ABI, Python shapes, Annex B verdicts; `USL[12][4]` stays 0.24.
- **Hashes.** In `tests/hash_gate.rs` `n` is per platform since Round 1, `n_specific` was re-frozen in Round 2, `time_axis` is unchanged; `n` is identical before and after Round 2 (the evidence that F-07 leaves totals untouched).
