- [ZWST 前端根因](../2026-11-05-zwst-root-cause-118322f/report.md)：四個穩態 WAV 改用 Annex A 濾波器及 0.2 s time skip 後，在固定 `2√2 Pa/FS` 換算下，總響度相對誤差可由約 −0.77%～+0.82% 降至 ≤0.001%。
- [Annex B 換算偏差](../2026-11-05-annexb-bias-118322f/report.md)：校準檔與 `2√2 Pa/FS` 換算不同，另造成約 +0.15% 響度偏差。此項必須與濾波器效果分開。

## 3. 實驗設計

1. **輸入與參考。** 從原始 Annex B WAV／工作簿及官方 C 重新取得資料；驗證 hash、欄位、單位與場型（訊號 15 為 diffuse）。確認官方 C 原檔及只改一格的版本差異。
2. **F-03。** 同工具鏈建置 0.22／0.24 C 版本，重新跑訊號 2–25；逐點比對 N，分別列全部點、兩版本不同點、差距 ≥`2e-4 sone` 的點。用十進位輸出精度處理四捨五入邊界，報告閾值附近敏感性；不得以 Annex B 的 5% 容差作為選定係數的依據。
3. **比響度。** 重驗四個穩態訊號 N′；補驗工作簿中時變訊號 6–13 所提供的 N′ 參考點。列出實際覆蓋格數、最大誤差與首個異常座標；未覆蓋者明記 PARTIAL。
4. **前端及校準因子。** 對訊號 2–5 建立「MoSQITo／Annex A 前端 × 校準檔／2√2 換算」矩陣，固定下游計算；分別報告絕對誤差、相對誤差與改善倍數。以相同輸入計算 filter-only 差，不能將換算效果歸入濾波器改善。
5. **機制與負控制。** 記錄各頻帶位準、0／0.2 s time skip 敏感性及單頻帶替換結果；檢查解析頻率響應是否包含降採樣路徑的限制。加入不觸發 USL 爭議格或旁路頻譜前端的控制，檢查是否將局部階段差異誤說成最終輸出完全無交互作用。
6. **範圍判讀。** 對「誤差全部來自前端」「四個訊號改善可推廣至所有訊號」「工作簿由 0.22 程式產生」分別給出證據強度；一般化未測就保留未測。這是數值與歸因驗證，不是新前端的完整產品驗收。
