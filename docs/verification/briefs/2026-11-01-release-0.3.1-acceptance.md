## 1. Question

Release commit `30e4279` (`30e427963da88db8b23e82cf612f047f36cd164b`, "release: 0.3.1") is pushed to `main`, CI run 41278186406 is green, the artifacts are built and hashed in `docs/RELEASE-0.3.1-2026-11-01.md`, and the tag is not yet created. The release claims:

- C-02: batch functions reject NaN / ±Inf samples with `Iso532Error::NonFiniteInput { idx }` (code 4, `ISO532_ERR_NONFINITE_INPUT`, Python `ValueError`); the stream path is unchanged.
- C-01: the output grid `frames = ceil(ceil(L/24)/4)` is frozen as a contract; point `j` sits at exactly `96j/48000` s and depends only on samples `≤ 96j`.
- V-01: the Annex B validator used by the tests applies the workbook rule `max(0.1, 0.05·|ref|)` and fails closed on invalid data.
- No numeric output changes for finite input compared with `v0.3.0`.

Independently decide whether each claim holds on the frozen commit and whether anything blocks the tag.

Stream: a NaN sample is zeroed, the next output frame carries `NONFINITE_INPUT`, the flag is still reported after `flush`, and the numeric output equals the stream fed with `0.0` at that position bitwise. 4. **C-01 with an independent harness.** For `L ∈ {4800, 4801, 4823, 4824, 4825, 4895, 4896, 4897, 24013, 47905, 47916, 47927, 47928, 47952, 47999, 48000}` compute `ceil(ceil(L/24)/4)` yourself and compare with `zwtv_out_frames`, `iso532_zwtv_out_frames`, the Rust result lengths (`n`, `time_axis`, `n_specific = 240·frames`) and the Python array shapes. Assert `time_axis[j].to_bits() == ((96*j) as f64 / 48000.0).to_bits()`. Prefix determinism on real signals: for at least three Annex B WAVs, cut the signal at a length that is not a multiple of 96 and compare every point of the short result with the same point of the full result bitwise (`n`, `time_axis`, all 240 Bark rows). Stream: feed one Annex B signal with your own chunk sequence (including chunks of 1 sample and chunks larger than 96) and compare point count and values with the batch result. ## 3. Rules of evidence

- Every number is produced by a script in the delivery folder and is reproducible from the frozen commit, the recorded toolchain and the Annex B WAV hashes. Harness sources are delivered; they are recorded separately from the tested sources.
- Bitwise comparisons report `f64::to_bits` / `struct.pack` hex, not printed decimals.
- Passed / failed / blocked / skipped / partial are reported per item of §2; a gap stays a gap. Historical evidence (0.3.0 rounds) is not promoted to passed.
- MoSQITo is not a reference for this round. Any divergence from the official C program or from the release record is written as 「發現／目前判斷」, never as "bug".
- Do not follow a moving `main`. If `main` advances during the round, the tested commit stays `30e4279`.
