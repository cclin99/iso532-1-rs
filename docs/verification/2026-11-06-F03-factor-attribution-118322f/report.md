# Annex B 誤差的因子歸因：MoSQITo 1.2.1、iso532 0.4.0、SQAT v2.0 與官方 C 程式

> 對照／Pair: [English](report.en.md) · 來源：zh · 同步 2026-11-06

主代理（Claude Fable 5.1），2026-11-06（Asia/Taipei）。受驗快照 `62e8559`（`iso532` crate 與 `v0.4.0` = `118322f` 逐位元相同）。與 Astra 平行進行的全因子輪互不參考（其資料夾未閱讀）。預註冊：`preregistration.zh-TW.md`；重現步驟：`replay.md`；所有數字出自 `results.json`（由 `analyze.py` 產生）。

## 1. 結論

1. **時變路徑上，iso532 0.4.0 與官方 C 程式只差兩個常數；在工作簿的解析度下沒有其他差異。** F1 `USL[12][4]`（0.24 對 0.22）使 N(t) 最多移動 0.0169 sone。F2 是邊界常數 `_ZUP += .0001f`（C 第 862 行；SQAT 第 528 行照抄；MoSQITo 與 iso532 沒有），使 N(t) 最多移動 1.8e-4 sone，而且就是改完 F1 後剩下的全部殘差（iso532 0.22：訊號 9／14／15 最大 2.19e-4）。兩個都切換後，用 iso532 自己的非線性衰減輸出算出的 N(t) 對工作簿的符合程度與 SQAT 0.22 完全一樣：最大 7.9e-5，48,711 點中 45,487 點在 5e-5 內，12,287 個決定性點中 11,224 點在 5e-5 內（點數與 SQAT 0.22 相同），並且與 SQAT 0.22 本身的差 ≤ 1.9e-12（訊號 11–13 ≤ 6.5e-8，見 §6）。
2. **SQAT v2.0 與官方程式只差 F1**（H1）：出貨值 0.24 → 最大 0.0169；改一格 → 捨入層級。
3. **MoSQITo 1.2.1 差 F1 + F2 + 自己的斜率／時間加權偏差 F-04～F-07（F7）**：把那一格改成 0.22 後最大誤差仍為 0.0233 sone；F7 本輪不可切換，整個殘差都量成 F7，因為 F6（非線性衰減初始狀態）在 Annex B 上沒有作用（§4.3）。
4. **iso532 `zwst` 與 MoSQITo 的穩態誤差（訊號 2–5：+0.23 %、+0.82 %、+0.42 %、−0.77 %）不受 F1、F2、F3 影響**：來源是前端（MoSQITo 的 Butterworth／FFT 1/3 倍頻程頻譜），印證 2026-11-05 的 ZWST 根因輪。SQAT 的 Annex A 前端加 0.2 s 跳過在 0.0013 % 內；不跳過在 0.094 % 內。
5. **F3（C 程式的 binary32 常數）使 N 改變 ≤ 9.0e-7 sone**，在四位小數層級無關。**F4（校準檔換算，+0.0226 dB）**使 N 提高約 +0.15 %（最大 0.070 sone），並使四位小數一致崩掉（2,920 點，對照 45,487 點），所以工作簿是用 2√2 換算產生的，與來源輪一致。
6. **F2 的機制已數值確認**：C 程式把第 0 帶積分在 0.9001 Bark 而非 0.9（後面各帶首尾相消），所以 N 多出 1e-4 × 第 0 帶核心響度；每個受影響訊號的平均 F2 效應與 1e-4 × nm[0] 的平均值到三位有效數字相等（例如 14：8.0e-5／8.0e-5；15：1.164e-4／1.164e-4），相關係數 0.91–0.99；沒有低頻能量的訊號（6–8、10–13、20–23、25）效應恰為零。被移位的帶邊夾住的斜坡段再在 N′ 上加 ≤ USL × 1e-4。
7. 因此，使用者說「0.24 不能作為單一因素」在這個精確意義上是對的：F1 是唯一達到 2e-4 決定性點門檻的因子，但 MoSQITo 血緣在 F1 之後的殘差是第二個獨立、可加的常數（F2），不是雜訊、不是前端、不是初始狀態。

## 2. 範圍與凍結

- iso532 於 `62e8559`（`git diff 118322f HEAD -- iso532/` 為空），由 harness 從主工作樹以 release 建置；rustc／cargo 版本見 `results.json["frozen"]`。
- 官方 C CLI 輸出：2026-11-05 輪的兩個 MSVC x64 `/O2 /fp:precise` 建置（v022 未修改 = 0.22f，v024 改一格），2√2 浮點 WAV，CSV 輸出四位小數。
- SQAT v2.0（`ggrecow/SQAT` tag `v2.0` = `94f489c…`）`Loudness_ISO532_1.m`，GNU Octave 11.3.0。四個變體：含常數的 0.24 與 0.22（2026-11-05 執行）、`ZUP = ZUP+0` 的 0.24 與 0.22（本輪；交付一行 diff）。
- MoSQITo 1.2.1：2026-11-05 執行的輸出（出貨 0.24 與執行期綁定 0.22）。
- 工作簿：Annex B 三本 `.xlsx`（data_only），容差 `max(0.1, 0.05·|ref|)`；「四位小數一致」= |Δ| ≤ 5e-5 + 1e-9；決定性點 = 兩個 C 建置相差 ≥ 2e-4 的 12,287 個工作簿點。
- 未閱讀：Astra 的 `2026-11-06-F03-factorial-matrix-118322f/` 與 `2026-11-06-F03-three-implementations-118322f/`。

## 3. 方法

把 C 程式的斜率階段（`f_calc_slopes`）與時間加權移植成 binary64 Python（`slopes_port.py`），帶三個開關：F1（`USL[12][4]`）、F2（加到每個 ZUP 的常數）、F3（斜率階段所有常數先捨入到 binary32）。移植版的輸入是 Rust harness（`harness/`）dump 出的 iso532 自身階段輸出：訊號 6–25 為非線性衰減輸出（21 × n_time），涵蓋 F4 ∈ {2√2, 校準檔} × F6 ∈ {零, MoSQITo 尾端}；訊號 2–5 為 `zwst` 的核心響度；訊號 1 為位準的核心響度。

移植版驗證（`validate.log`）：F2 = 0 時在 20 個時變訊號上重現 iso532 的 N(t) 到 2.1e-14 以內，訊號 1 的總響度到最後一位；F2 = 1e-4 時在 17 個訊號上重現 SQAT 0.24 到 1.9e-12 以內，訊號 11–13 到 6.5e-8 以內（N′ 1e-7 以內）。因此關掉常數時移植版就是 iso532、開啟時就是 SQAT，全因子的每一格都是同一條管線上受控的單因子變體。

訊號 6–25 全因子：F1 × F2 × F3 × F4 × F6 = 32 格 × 20 訊號（另加負對照 `USL[12][4] = 0.30`）。訊號 2–5：iso532 前端上 F1 × F2 × F3 × F4，加 SQAT 三種前端水準 × F1 × F2。訊號 1：F1 × F2 × F3。此外 F2 也直接在 SQAT 內切換（Octave），讓歸因不只依賴移植版。

## 6. 跨實作恆等（完整 2 ms 格點，不只工作簿點）

- 移植版(F2 = 0) 對 iso532 0.4.0：20 個時變訊號皆 ≤ 2.1e-14。
- 移植版(F2 = 1e-4, 0.24) 對 SQAT 0.24（Octave，2026-11-05）：17 個訊號 ≤ 1.9e-12；訊號 11、12、13（1 kHz 音脈衝 50 ms／500 ms／組合）為 1.7e-8、1.0e-8、6.5e-8，各 121–195 幀，N′ ≤ 1.0e-7。這三個訊號在每種 F1／F2 組合下都是同樣的差，且拿掉常數的 SQAT 對 iso532 出貨版也是同樣的量，所以這是斜率階段上游（SQAT 的 1/3 倍頻程或非線性衰減實作對 iso532）在暫態時的差異，不是斜率階段。它比工作簿解析度低三個數量級，未追查。
- SQAT(F2 = 0, 0.24) 對 iso532 0.4.0 出貨版、SQAT(F2 = 0, 0.22) 對移植版(0.22, 0)：見 `results.json["validation"]`（`sqat_eps0_*`），於 §7 填入。

## 8. 對專案的意義

- `iso532` 0.4.0 時變路徑 = SQAT v2.0 − {F1, F2}。兩個常數獨立且可加；F2 對 N 的副作用是 1e-4 × 第 0 帶核心響度（Annex B 上 ≤ 1.8e-4 sone，≤ N 的 0.0014 %），對 N′ 在斜坡取樣點 ≤ USL × 1e-4。iso532 是否採用 C 程式的這個常數（它是 C 格點迴圈的穩健性 epsilon，對 N 的影響是副產物；iso532 用捨入到 1e-8 取得同樣的格點穩健性）由使用者決定，與 `USL[12][4]` = 0.22、ZWST 前端一併考慮（0.5.0 候選集合）。兩者都採用後，官方程式的 Annex B 表格可用未修改的 golden 產生流程重現到四位小數。
- 0.4.0 驗收用的全序列 total 1e-4 門檻（`project-c01-root-cause`）其實是在吸收 F2；套用 F2 與 F1 後，對 C 程式可達的門檻是 CLI 自身的四位小數捨入（1e-4 絕對），對 SQAT 是 1e-12。
- MoSQITo：F1、F2 之外，F-04～F-07 讓它的最大誤差不論那一格是多少都停在 0.023 sone；穩態前端帶著 0.2～0.8 % 的誤差。
- 工作簿是以 2√2 換算產生：校準檔換算下沒有任何一格達到四位小數一致。

## 9. 限制

- F7（MoSQITo F-04～F-07）未切換；其大小由 MoSQITo 0.22 對 C 格讀出。
- F3 只套用在斜率階段；C 程式核心響度階段的 `0.0635f`、`1.0f`、`0.4f`、`0.32f` 未模擬（相對效應 ≈ 2e-8）。
