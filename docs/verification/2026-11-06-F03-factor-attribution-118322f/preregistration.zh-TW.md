# 預註冊：MoSQITo、iso532、SQAT 與官方 C 程式對 Annex B 誤差的因子歸因

主代理（Claude），2026-11-06（Asia/Taipei）。凍結快照 `62e8559`（`iso532` crate 與 `v0.4.0` = `118322f` 逐位元相同；`git diff 118322f HEAD -- iso532/` 為空）。本文件在全因子執行前寫成；促成 H2 的診斷列在 §4，讓確證性與探索性結果分開。Astra 平行進行的一輪（`docs/verification/2026-11-06-F03-factorial-matrix-118322f/`，進行中）未閱讀。

## 1. 問題

把 `USL[12][4]` 改成 0.22 之後，SQAT v2.0 對 Annex B 工作簿的誤差降到四位小數捨入層級（決定性點最大 6.5e-5），但 iso532 0.4.0 仍殘留最大 2.2e-4（訊號 9、14、15），MoSQITo 1.2.1 殘留 0.023。哪些實作因子——單獨與組合——解釋每個實作對工作簿（由官方 C 程式產生，見 `2026-11-05-F03-workbook-provenance-118322f`）的誤差？

## 2. 因子與水準

| 代號 | 因子 | 水準 | 各實作 |
|---|---|---|---|
| F1 | `USL[12][4]` | 0.24 / 0.22 | C 0.22；SQAT、MoSQITo、iso532 0.24 |
| F2 | 每個 ZUP 加上的邊界常數（C 第 862 行 `_ZUP += .0001f`；SQAT 第 528 行） | 0 / 1e-4 Bark | C、SQAT 1e-4；MoSQITo、iso532 0 |
| F3 | 斜率階段的常數先捨入到 binary32（`0.9f`、`0.1f`、`.0001f`、表格項） | 關 / 開 | C 開（表格宣告為 `double`，常數寫成 `float`）；SQAT、MoSQITo、iso532 關 |
| F4 | int16 WAV 的壓力換算 | 滿刻度 = 2√2 Pa / Annex C 校準檔（比值 1.0026058976668580，+0.0226 dB） | 工作簿為 2√2（來源輪）；簡報的換算 (b) 為校準檔 |

F1～F3 在官方 `f_calc_slopes` 與時間加權的 binary64 Python 移植版（`slopes_port.py`）切換，輸入為 iso532 自己的非線性衰減輸出（`harness/`，出貨表格）；F4、F6 在 Rust harness 切換；F5 用 SQAT（Octave）與 iso532 `zwst` 前端。F2 另外直接在 SQAT 內切換（`sqat/var-e0-0{22,24}`，Octave 11.3.0），讓歸因不只依賴移植版。

訊號 6–25 全因子：F1 × F2 × F3 × F4 × F6 = 32 格 × 20 訊號。訊號 2–5：iso532 前端上 F1 × F2 × F3 × F4，加 SQAT 三種前端水準 × F1 × F2。訊號 1：F1 × F2 × F3（輸入為位準）。

## 3. 假設（確證性）

- H1 F1 單獨在 12,287 個決定性點上使 N(t) 最多移動 0.017 sone，且是 SQAT 對工作簿差異的全部（SQAT 0.24 → 0.22 後決定性點 ≤ 1e-4）。
- H2 F2 是 F1 之後 iso532／MoSQITo 對 C 的殘差：F2 = 1e-4 時移植版重現 SQAT（相同 F1）到 ≤ 1e-12，並在全部 25 個訊號上達到工作簿的四位小數層級；F2 = 0 時殘差 ≈ 1e-4 × 第 0 帶核心響度（加斜坡取樣點上 ≤ USL × 1e-4），因此在低頻為主的訊號（9、14、15）最大，在 6–8、10–13、16–25 可忽略。
- H3 F3 使 N 改變 < 1e-5 sone（相對 ≈ 5e-8），不是達到工作簿四位小數一致所需；可能讓與 C CLI 完全相同（四位小數）的點數改變數個百分點。
- H4 F4 在每個訊號上把 N 乘以 ≈ +0.15 %（乘法性，與 F1～F3、F6 獨立）；在校準檔換算下沒有任何一格達到工作簿的四位小數層級。
- H5 F5：MoSQITo Butterworth 前端就是 0.2～0.8 % 的穩態誤差（zwst 根因輪）；SQAT 的 Annex A 前端加 0.2 s 跳過在捨入層級；`time_skip = 0` 使 N 改變 ≤ 0.1 %。
- H6 F6 只影響起始安靜訊號的前約 0.5 s，之後的決定性點不受影響。
- H7 跨實作恆等：SQAT(F2 = 0, F1 = 0.24) ≡ iso532 0.4.0 出貨版，訊號 6–25 的 N(t) 差 ≤ 1e-12（兩實作在時變路徑上恰好只差 F1 與 F2）；SQAT(F2 = 1e-4, F1 = 0.22) ≡ 移植版(0.22, 1e-4) ≤ 1e-12。

負對照：移植版 USL[12][4] = 0.30 的誤差必須比其他所有格大一個數量級（2026-11-05 的 SQAT 0.30：0.054）。

## 5. 指標

工作簿參考（2√2 換算，`openpyxl` data_only），同 2026-11-05 分析：穩態 N 與 240 格 N′；時變 N(t) 於工作簿時間點、Nmax、依工作簿公式的 N5、指定 Bark 的 N′(t)（6–13）；容差 `max(0.1, 0.05·|ref|)`；決定性點 = 官方 C 0.22 與 0.24 CLI 差 ≥ 2e-4（12,287 點）；「四位小數一致」= |x − ref| ≤ 5e-5 + 1e-9。因子效應 = 開啟該因子的格減去同格關閉，取全部工作簿點上的 max |Δ| 與移動 ≥ 1e-9 的點數。
