## 2. 修正的數學與程式依據

官方 `f_nl` 在每個 critical band 開始時令 `UoLast = 0`、`U2Last = 0`。本次 scalar 與 AVX2 路徑都由 `NlInit::Zero` 建立相同零狀態；標準 batch API、processor 預設、Python 預設及 C ABI 均進入這條路徑。

舊模式 `MosqitoTail` 明確保留尾端 seed，僅供歷史數值與 MoSQITo 相容比較，仍具有 F-02 的非因果性。測試同時要求它能重現舊反例，因此不會把「完全未觸發問題」誤當修正成功。

24 個內插步驟、下一個內部 frame 的讀取及 2 ms 輸出網格未變。前綴不變性只比較由已有樣本充分決定的輸出：保守排除最後一個內部 frame。這不是零延遲宣告，也不要求尚未完整收到的最後一個 frame 無條件等價。

另將 21-band core 直接送進新編譯的官方 `f_nl`，避開 WAV、校準、濾波及總響度積分等共同因素。C 行首、行尾 sentinel 與有限值檢查皆通過。

- 外部 judge 拒絕 empty、NaN、Inf、shape 不合、反轉 bounds，測試邊界值、1% 附近、±一個樣本與 endpoint；**19/19 負向／邊界控制通過**。
