# Independent C-01 / C-02 contracts

Run `contracts/run.ps1` from the repository root after the parent frozen-source archive and formal maturin environment are ready. Rust harness paths resolve only to `tmp/acceptance-031/source` (commit 30e427963da88db8b23e82cf612f047f36cd164b). Cargo.lock was seeded from that archive and then reduced by Cargo to the independent harness dependency closure; this retains source-lock dependency versions. Binaries remain under tmp/acceptance-031/contract-target.

`rust-results.jsonl`, `c-results.jsonl`, and `python-results.json` are actual execution records. `summarize.py` generates `results.json` and exits nonzero for any failed case. The Rust harness also exits nonzero on any failed assertion; C and Python independently do the same.

All 16 specified lengths are checked. Prefix comparisons include the three official Annex B WAVs (signals 3, 5, 10), with 4801, 24013, and 47927 samples per signal; broadband_570 is an additional local input, not another official signal. Signal 3 is a 44.1 kHz signed 16-bit WAV: `prepare-sig3.py` independently scales PCM to pressure and resamples it using scipy.signal.resample_poly(160,147), with exact input/output hashes and tool versions in sig3-input.json. This resampling is a fixture preparation step, not an official-reference numerical comparison. Native 48 kHz inputs are independently decoded by hound and scaled by 2*sqrt(2)/2^(bits-1). Prefix checks compare every n, time_axis, and all 240 Bark rows via f64::to_bits. On failure they emit first mismatch coordinates and both hexadecimal words; successful cases emit representative hexadecimal n words.

Rust stream uses cyclic chunks [1,131,7,409,24,97] against the entire official signal 10, checking count, frame indices, and n bits. Stream NaN cases separately assert the exact next flagged output frame (sample 0 -> frame 0; sample 101 -> frame 1) and postflush residual flag at tail sample 4799. Rust and C compare n and n_phon bitwise against zero-substitution control; the C test additionally reads the residual flag twice to check persistence.

C boundary scenarios: 0 = bad sampling rate plus NaN (3); 1 = too short plus NaN (2); 2 = two nonfinite samples (4); 3 = minimum positive subnormal; 4 = +0; 5 = -0; 6 = 1e300. C does not expose the nonfinite sample index; index precedence is checked in Rust and Python. All 12340 prefilled C doubles stay untouched on nonfinite error. Huge finite values return LevelExceeds120dB/code 1, and subnormal/zeros succeed.

C compiler initialization emits a nonfatal `vswhere.exe` not found message, followed by successful x64 environment initialization, compilation and execution. /utf-8 is explicit; the generated header is compiled directly from the frozen snapshot. No production code, tests, golden data, or Git metadata were changed by this subtask.
