# ZWST 對 Annex B 誤差的根因

> 對照／Pair: [English](report.en.md) · 來源：zh · 同步 2026-11-05

Claude（Opus 5.5，主代理，非 Astra），2026-11-05 Asia/Taipei。受測：`v0.4.0` = `118322f` 的 `iso532` crate（主樹 `iso532/` 與 tag 位元相同）。延續 [`2026-11-05-annexb-bias-118322f/`](../2026-11-05-annexb-bias-118322f/report.md)。

## 結論

- **ZWST 的誤差全部來自頻譜前端。** ZWST 刻意沿用 MoSQITo 1.2.1 的 `noct_spectrum`（6 階 Butterworth 帶通濾波器，依 ANSI S1.1-1986 設計），而 ISO 532-1 Annex A 用的是標準自己定義的參考濾波器（Table A.1／A.2）。兩者的設計目標不同：
  - Annex A 的濾波器在相鄰頻帶中心處恰好衰減 **−20.00 dB**，有效噪音頻寬比精確 1/3 倍頻程寬 2.0%～4.2%。
  - MoSQITo 的濾波器把有效噪音頻寬對齊到精確 1/3 倍頻程（1.000），代價是相鄰頻帶中心只衰減 **−19.4 dB**，高頻區更退化到 −17.5 dB。
- **這兩項差異完整解釋了觀察到的誤差：**
  - 純音：漏進「下方」相鄰頻帶的能量多約 0.6 dB。Zwicker 模型的低頻側沒有掩蔽斜率，所以這些能量會直接加到響度上，結果偏高 +0.23%～+0.82%。上方頻帶的漏入會被上側斜率蓋掉，不影響總響度。
  - 噪音：每個頻帶的有效頻寬窄約 0.1 dB，粉紅噪音因此偏低 −0.77%。
- **用 Annex A 的穩態方法**（同一組 ISO 濾波器組，從 0.2 s 開始取均方值，即 `ISO_532-1.c` 的 `f_square_and_smooth`）重算：
  - 用校準檔換算時，跟官方 CLI 到小數第四位完全相同。
  - 用 2√2 換算時，四個訊號對工作簿的誤差都 ≤ 0.001%。
- 時間範圍（是否略過開頭 0.2 s）的影響 ≤ 0.002%，可以排除。main loudness 和 slopes 已由訊號 1 證明跟工作簿一致。
- **這不是程式錯誤，是前端的設計選擇：** README 寫明 ZWST「刻意維持與 MoSQITo 相容的頻譜路徑」。要讓 ZWST 達到時變路徑的精度，就得換掉前端，屬於數值變更（見 §5）。

## 1. 方法

[zwst_frontend_harness.rs.txt](zwst_frontend_harness.rs.txt) 以 path 依賴 `iso532`，對 Annex B 訊號 2–5（Astra 2026-11-04 輪校準後的輸入）分別計算：

- `noct`：`iso532::zwst::noct_spectrum_rms`，即 ZWST 實際使用的前端。
- `noct_skip0p2`：同一個前端，但略過開頭 0.2 s。
- `iso`：用 `TOB_B`、`TOB_DELTA`、`TOB_GAIN` 建出 ISO 濾波器組，從第 9,600 個樣本開始取均方值，換算成位準。

三組位準都送進同一套 `main_loudness` 和 `calc_slopes`。歸因的做法是：從 `iso` 位準出發，每次只把一個頻帶換成 `noct` 的值，記錄總響度的變化。換算各跑兩次：一次用校準檔係數，一次乘以 0.997401（等於 2√2）。

[filter_response.py](filter_response.py) 從原始碼解析出兩組濾波器實際使用的係數（`NOCT_SOS` 在 48 kHz／`NOCT_DECIM_Q` 下；ISO 濾波器在 48 kHz 下），計算頻率響應。

## 5. 選項（需要決定，本輪不改程式）

| 選項 | 內容 | 影響 |
|---|---|---|
| A. ZWST 預設改用 Annex A 穩態方法 | 用現有的 ISO 濾波器組加均方值；需要決定 time skip 怎麼定（官方 CLI 由使用者指定，工作簿對應 0.2 s） | 數值變更，0.5.0；對 Annex B 誤差從 0.2%～0.8% 降到 ≤ 0.001%（2√2 換算）；對 MoSQITo 的 ZWST 差距會變成 0.2%～0.8% |
| B. 新增 Annex A 穩態函式，保留現有 ZWST | 例如另一個函式或選項，仿照 `NlInit::MosqitoTail` 的做法 | 新功能，0.5.0；現有輸出不變；使用者要自己選 |
| C. 維持現狀，只補文件 | 在 README 寫明前端差異的大小與原因 | 不改版號 |

我的建議是 **A，同時保留 MoSQITo 相容前端作為選項**。理由是 0.4.0 的 D1 已經把正確性參考定為 Annex A，時變路徑也依此對齊了，穩態路徑維持另一套前端反而不一致；仿照 `NlInit::MosqitoTail` 的模式，也能讓需要跟 MoSQITo 比對的使用者繼續使用。這就是先前列為「穩態前端待決」的議題，應該照 0.4.0 的流程走：先出決策備忘、phase 計畫，實作後交 Astra 驗收。

## 6. 限制

- 只用 Annex B 的四個穩態 WAV 訊號（2–5）；其他穩態輸入的誤差大小會依頻譜形狀而不同，但機制相同。
- 頻率響應是用解析出的係數計算的理論響應；ZWST 對低頻帶會先降採樣，降採樣濾波器的影響沒有另外分離（對訊號 2–5 影響最大的頻帶多半不需要降採樣，只有訊號 2 的 158/200 Hz 頻帶 q = 2）。
- 「MoSQITo 濾波器高頻區退化來自 bilinear 轉換」是推論。
