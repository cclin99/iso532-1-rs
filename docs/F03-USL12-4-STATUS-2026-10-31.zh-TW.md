## 0. 一句話結論

現有測試**無法分辨** 0.22 與 0.24（兩值在每個可觸發案例上都落在 Annex B 容差內）；權威來源方面**已確認 ISO 532-1:2017 的 2017-11 修正版確實更正了 Table A.9**，但更正的是哪一格、由何值改為何值、原因為何，全部未知；實作沿革上 0.22 與 0.24 各有一手來源。改表門檻維持 PENDING，`tables.rs:86` 維持 0.24。

## 2. 證據記分板（實作沿革，不是標準正值）

| 0.22 | 0.24 | 未知 |
|---|---|---|
| 官方 Annex A C 附件（保存檔，`0.22f`；說明檔帶 ISO_DIS／2016 字樣） | MoSQITo 1.2.1 | **ISO 532-1:2017 corrected 2017-11 Table A.9 的該格**（已確認 A.9 被更正；格、值、原因未知） |
| 1991 Zwicker／Fastl 等 BASIC 程式原刊（一手） | SQAT v1.0／v1.3／main（來源鏈自稱 2014 C → AARAE 2015） | 2017-06 原版同格 |
| MetaSona（刻意採 0.22，來源為供給的 C 檔） | 本案 Rust（承自 MoSQITo） | 2014 版 C 附件與保存檔是否同一版本 |
| 未核實鏡像的線索：印刷 p.27、Index 6、`0.300 ≤ N′ < 0.420`、critical band 5 → 0.22（只作定位，不作證據） | | AARAE 2015 原始檔實際值 |

一個值得注意的張力：SQAT 自稱源於「2014 Annex A C 程式」卻是 0.24，而本案保存的官方 C 是 0.22f。可能的解釋有二：2014 的 C 與現存附件不是同一版（暗示 C 附件曾更新，可能與 2017-11 更正相關），或 AARAE 轉寫時改了值。這是**假說**，驗證方式是取得 AARAE 2015 原始檔與 2014 C 檔，不需要付費標準。

## 3. 這格影響多大

- 只在「頻帶邊緣比響度落在 0.30–0.42 sone/Bark 區段、且 band index 為 4」時被用到；決定比響度圖形該處的高頻側斜率。
- 量到的最大影響：時間加權前總響度 0.016 sone、比響度 0.010 sone/Bark（定向人工輸入）；真實 Annex B 訊號 14 的總響度對 C 的殘差從 0.0151 變 0.0128 sone。Annex B 容差在這些量級是 0.1 sone 以上。
- 以 MoSQITo golden 做 parity 的測試若改 0.22 會斷掉；那證明與 MoSQITo 不同，不證明違反 ISO。
